# She's Digital · Home v2

Rediseño de la página de inicio de [sheisdigitalab.com](https://sheisdigitalab.com), en revisión.

- HTML, CSS y JavaScript sin dependencias de compilación.
- Movimiento con GSAP + ScrollTrigger y scroll suave con Lenis. Con «reducir movimiento» activado, la página se muestra completa y sin animaciones.
- Paleta del logo (#7CBCAD), Space Grotesk + Inter y una escala tipográfica cerrada de 6 tamaños.

La versión oficial sigue publicada en sheisdigitalab.com; esta copia lleva `noindex` para no duplicar contenido en Google.

Diseñado por She's Digital · Barcelona.
